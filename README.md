## Исследуемые индустриальные кейсы и наборы данных

В рамках курсового проекта реализован комплексный первичный аудит и предварительная обработка четырёх разнородных типов данных для решения прикладных задач искусственного интеллекта:

### 1. Табличные данные: Прогнозирование стоимости медицинской страховки
* **Кейс:** №58 (Индустриальный партнёр: ОГБУ «ЧРЦНИТ»).
* **Файл данных:** [`data/tabular/insurance.csv`](data/tabular/insurance.csv) (1 338 записей, 7 признаков).
* **Решаемая задача:** Вещественная регрессия — прогноз годовых индивидуальных расходов на медицинское страхование клиентов.
* **Методология первичного анализа:**
  - Дедупликация и проверка целостности структуры;
  - Анализ асимметрии распределения целевой переменной `charges` ($\gamma_1 = 1.51$);
  - Логарифмическое преобразование $\ln(y)$ для нормализации остатков;
  - Робастное масштабирование признаков (`RobustScaler` / IQR) и унитарное кодирование категорий (`One-Hot Encoding`).
* **Аналитические сценарии:** [`notebooks/1_3_4 table_5.py`](notebooks/1_3_4%20table_5.py) ... [`notebooks/1_3_picture(1_2).py`](notebooks/1_3_picture(1_2).py).

### 2. Временные ряды: Коррекция массового расхода кориолисового расходомера
* **Кейс:** №60 (Индустриальный партнёр: НИЛ Технической самодиагностики ЮУрГУ / ПАО «Северсталь»).
* **Файл данных:** [`data/timeseries/tuv_nel_data.csv`](data/timeseries/tuv_nel_data.csv) (715 отсчётов, 6 синхронных каналов).
* **Решаемая задача:** Временная регрессия и фильтрация нестационарных сигналов в условиях двухфазного газожидкостного потока.
* **Методология первичного анализа:**
  - Оценка эффекта завоздушивания трубы: падение измеренного расхода на 42% при объемном газосодержании GVF > 30%;
  - Спектральный анализ высокочастотного измерительного шума;
  - Сглаживание и фильтрация сигналов фильтром Савицкого-Голея (достигнутое отношение сигнал/шум $\text{SNR} = 37.8\text{ дБ}$);
  - Формирование матрицы скользящих временных лагов ($t-1, t-2, \dots, t-k$) для обучения рекуррентных сетей.
* **Аналитические сценарии:** [`notebooks/2_3_1_picture(3).py`](notebooks/2_3_1_picture(3).py) ... [`notebooks/2_3_4_picture(5).py`](notebooks/2_3_4_picture(5).py).

### 3. Компьютерное зрение: Детекция средств индивидуальной защиты (СИЗ)
* **Кейс:** №48 (Индустриальный партнёр: ПАО «Челябинский кузнечно-прессовый завод», ПАО «ЧКПЗ»).
* **Файлы аннотаций:** [`data/images/README.md`](data/images/README.md) (выборка из 2 600 кадров, 918 bounding box аннотаций в формате YOLO).
* **Решаемая задача:** Object Detection — автоматический контроль соблюдения правил охраны труда на опасном производстве.
* **Методология первичного анализа:**
  - Аудит распределения геометрических размеров ограничивающих рамок ($w_{\text{norm}}, h_{\text{norm}}$);
  - Выявление критического дисбаланса классов: класс нарушений (`NO-Hardhat`) составляет менее 16% от общего числа меток;
  - Математическое обоснование применения взвешенных функций потерь (`Focal Loss`);
  - Разработка стратегии фоновых аугментаций (`Mosaic`, `HSV-Jitter`) для подавления бликов металлообработки.
* **Аналитические сценарии:** [`notebooks/3_3_picture(7_8).py`](notebooks/3_3_picture(7_8).py).

### 4. Обработка естественного языка (NLP): Определение тематики обращения граждан
* **Кейс:** №68 (Индустриальный партнёр: ОГБУ «ЧРЦНИТ» / ПАО «Сбербанк»).
* **Файл корпуса:** [`data/text/premise_question_answer4.txt`](data/text/premise_question_answer4.txt) (текстовый корпус диалогов Koziev NLP).
* **Решаемая задача:** Семантическая классификация и информационный поиск по текстовым обращениям граждан.
* **Методология первичного анализа:**
  - Очистка от пунктуации и служебных токенов регулярными выражениями;
  - Морфологический анализ и лемматизация на базе библиотеки `pymorphy3`;
  - Фильтрация стоп-слов русского языка (удалено >60% шумовой лексики);
  - Построение частотных словарей и сравнительных облаков слов (`WordCloud`);
  - Расчет матриц весов `TF-IDF` и программная реализация информационного поиска по косинусному сходству векторов (`Cosine Similarity`).
* **Аналитические сценарии:** [`notebooks/4_3_picture(9_10).py`](notebooks/4_3_picture(9_10).py).

## Инструкция по установке и воспроизведению

### 1. Клонирование репозитория
```bash
git clone https://github.com/flommmaaaa/coursework-data-analysis.git
cd coursework-data-analysis
```

### 2. Создание и активация виртуального окружения
* **В Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```
* **В Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск аналитических скриптов
Все расчетные сценарии поддерживают автономный запуск как из корневой директории репозитория, так и из папки `notebooks/`:
```bash
# Первичный анализ табличных данных
python notebooks/1_3_picture(1_2).py

# Первичный анализ временного ряда
python notebooks/2_3_1_picture(3).py

# Анализ bounding box разметки компьютерного зрения
python notebooks/3_3_picture(7_8).py

# NLP предобработка, лемматизация и облака слов
python notebooks/4_3_picture(9_10).py
```

### 5. Повторная сборка пояснительной записки (50 страниц)
Для перекомпиляции итоговых документов курсового проекта запустите сборочные пайплайны:
```bash
# Генерация PDF документа ровно на 50 страниц со стилями ГОСТ 7.32-2017
python src/main_build_50pages.py

# Генерация Microsoft Word (.docx) документа
python src/build_coursework_docx.py
```
Сгенерированные файлы сохраняются в директории `output/`.
